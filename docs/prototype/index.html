IdeaOS — Clickable Prototype

L1 fidelity (spec_05 §8). All links active · seeded demo graph · light/dark theme.

✦
This is a design-validation artifact, not production code — no backend, no live LLM. It exists to test the two journeys with real users before the first heavy UI build sprint (gates graph.S2). The non-directive promise (NFR-010) is visible in the UI: every AI claim shows a n8 · 88% badge and a confidence bar, and the decision controls are neutral and equal-weight.

Guided journeys (run these in the usability test)

Journey J-1

First-time onboarding & cold-start

Sign up → empty graph → guided import → first interview → first relationship → first value.

  1. Sign up & verify
  2. See the empty graph (import hero)
  3. Import / capture seed ideas
  4. AI interviews a seed idea
  5. Confirm the first relationship
  6. See the first lineage & twin
Journey J-2

New idea → conscious decision (the core loop)

Capture → interview → ancestry/twin → derivative scores → Reality Check → decide.

  1. Open the living graph
  2. Capture a new idea (⌘K)
  3. Answer the AI interview
  4. Ancestry classified, twin checked
  5. Review derivative scores
  6. Reality Check → record decision
